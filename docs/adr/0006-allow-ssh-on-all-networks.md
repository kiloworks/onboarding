# 모든 네트워크에서 SSH 인바운드를 허용한다

2026-10-19 magneto가 질문 7의 추천안을 변경하여 모든 네트워크에서 SSH 허용 규칙을 기본 설정하도록 결정했다. ADR 0005를 대체한다. 앱은 Tailscale 인터페이스로 한정하지 않고 Windows 방화벽의 네트워크 프로필 전반에서 SSH TCP 22번 인바운드를 허용한다.

사용자는 Tailscale 밖의 도달 가능한 네트워크에서도 SSH 연결을 받을 수 있다. 온보딩의 작업 설명과 완료 리포트에 실제 허용 범위를 명시한다. 기존 SSH 설정과 공개키는 보존하며 불필요한 다른 포트는 열지 않는다. 이 결정이 SSH 암호 인증이나 기존 인증 정책을 자동으로 변경하는 것은 아니다.

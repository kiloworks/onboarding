# 앱이 설정하는 SSH 접근은 Tailscale 경로로 제한한다

상태: 폐기됨 — 2026-10-19 후속 결정으로 모든 네트워크의 SSH 인바운드 허용을 기본값으로 변경했다. 현재 정책은 ADR 0006을 따른다.

2026-10-19 magneto 결정: 앱이 생성·관리하는 SSH 방화벽 허용 규칙은 Tailscale 경로로 제한하고 일반 네트워크에 TCP 22번을 새로 열지 않는다. 기존 프로젝트의 광범위한 인바운드 허용 규칙은 그대로 이식하지 않는다.

Windows에서 실제 인터페이스·주소·방화벽 조건이 목표를 충족하는지 검증한다. Tailscale 연결에서의 SSH 성공과 비Tailscale 경로에서 앱 규칙에 의한 접근 허용이 없음을 확인한다. 기존의 별도 광범위 SSH 허용 규칙을 어떻게 처리할지는 아직 미정이며, 기존 규칙이 남아 있으면 시스템 전체가 Tailscale 전용이라고 표시하지 않는다.

# ADR 0001: 온보딩에 SSH 원격 관리 준비를 포함한다

## 상태

승인됨 — 2026-10-19, magneto 결정.

## 배경

새 데스크톱 앱은 Keyport에서 별도로 발급·전달한 Tailscale 등록 키를 첫 실행에 입력받는다. 완료 범위를 네트워크 연결까지만 제한하거나, 기존 프로젝트의 원격 관리 준비 목적까지 유지하는 대안이 있었다.

## 결정

Tailscale 설치·등록·연결 확인과 함께 SSH 원격 관리에 필요한 서버·접근 키·방화벽 설정을 온보딩 범위에 포함한다. 기존 Windows 및 macOS 배포 파이프라인을 참고한다.

## 결과

플랫폼별 관리자 권한과 SSH 접근 정책을 설계·검증해야 한다. 기존 Windows 구현에는 OpenSSH와 공개키 설정이 있지만, 현재 확인한 macOS postinstall은 Tailscale 설치·연결까지만 수행한다. macOS SSH 준비를 기존에 완성된 기능으로 간주하지 않는다.

관리자 SSH 공개키를 전달·선택하는 방법과 플랫폼 지원 범위는 후속 결정으로 남긴다.

# 설치 후 운영

## 실패와 복구

다운로드·연결·SSH 준비 중 복구 가능한 단계는 한 번 자동 재시도합니다. UAC 거부와 로그아웃 동의는 반복하지 않습니다. 등록이 성공한 기기는 같은 일회용 키를 재사용하지 않고 남은 설정만 진행합니다. 키가 만료·소비됐거나 재등록이 필요하면 관리자에게 새 키를 요청합니다.

앱을 다시 실행해 현재 연결을 확인하고 복구를 시작할 수 있습니다. 기존 SSH 설정을 덮어써서 해결하지 않으며 호환되지 않는 설정은 리포트로 알립니다. 일반 계정에 UAC용 별도 관리자 자격 증명을 입력해도 SSH 대상은 앱에 표시한 원래 로컬 사용자입니다.

## 지원 리포트

마지막 화면에서 리포트를 복사해 관리자에게 비공개 전달합니다. 키 원문은 제외하지만 계정명·IP 등 정보는 포함될 수 있습니다. 로그 경로는 `%LOCALAPPDATA%\Kiloworks\Onboarding\install.log`입니다.

## 원격 관리 해제

앱 제거는 앱만 제거합니다. 원격 관리 권한을 해제하려면 관리자가 기존 사용 목적을 확인하고 다음을 별도로 처리합니다.

- 기본 공개키 두 줄만 해당 authorized_keys에서 제거합니다. 다른 운영자의 키는 삭제하지 않습니다.
- 앱 소유 방화벽 규칙 `Kiloworks-Onboarding-SSH`를 제거합니다. 다른 SSH 규칙이 있으면 별도로 검토합니다.
- 다른 서비스가 SSH를 사용하지 않는 경우에만 sshd를 중지·비활성화합니다.
- 필요하면 Tailscale 로그아웃과 tailnet 기기 삭제를 수행합니다.

등록 auth key 폐기·만료만으로 이미 등록된 기기는 제거되지 않습니다. 공통 관리자 개인키 분실·폐기 시 기존 기기의 해당 공개키도 갱신해야 합니다.

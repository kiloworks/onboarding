# Windows 첫 출시 제품 결정

2026-10-19 magneto의 질문 1~17 답변을 기록한다. 아래 확정 사항은 이전 추천안보다 우선한다. 구현 착수에 대한 최종 공통 이해 확인은 아직 진행 중이다.

## 플랫폼과 배포

- Windows 10을 최소 OS 제품군으로 보고 별도의 최소 기능 업데이트 버전을 임의로 두지 않는다. 실제 의존성의 호환 제약을 확인하며, 검증하지 않은 모든 Windows 10 빌드가 지원된다고 주장하지 않는다.
- x64와 ARM64를 첫 출시부터 지원한다. ARM64를 단순 x64 에뮬레이션 테스트로 대체하지 않는다.
- 공개 원격 저장소는 `kiloworks/onboarding`, 라이선스는 MIT로 한다. 기존 비공개 코드의 공개 가능 여부와 재사용 라이선스를 검토한다. 기존 Keyport HANDOFF는 별도 ajchemist 프로젝트의 인계 자료이며 이번 앱 요구사항이 아니다.
- Windows 설치 프로그램 EXE로 배포하고 시작 메뉴와 앱 제거를 지원한다. 코드 서명 인증서가 없으면 미서명 테스트 배포임을 명시한다.
- 첫 버전은 수동 다운로드·업데이트 방식으로 한다. 앱 제거는 앱만 제거하며 Tailscale·SSH 설정은 유지하고 별도 해제 절차를 문서화한다.

## 첫 실행과 권한

- 한국어 온보딩 화면을 먼저 일반 권한으로 표시하고, 작업 중 필요한 시점에 점진적으로 관리자 권한을 요청한다.
- SSH 대상은 설치를 승인한 기존 Windows 계정으로 한다. 관리자 계정으로만 제한하거나 새 계정·암호를 생성하지 않는다.
- 표준 사용자와 관리자 사용자의 SSH 공개키 경로·권한을 각각 처리한다. UAC에서 다른 관리자 자격 증명을 입력했을 때 원래 사용자와 승격 사용자를 혼동하지 않도록 계정을 명시하며, 정확한 대상 선택 의미는 구현 전 확인한다.
- 기본 관리자 공개키 두 개를 기존 키를 보존하며 중복 없이 추가한다.

## Tailscale 연결과 업데이트

- Keyport에서 발급해 전달받은 24시간 일회용·사전 승인 auth key를 첫 실행에 입력받는다. 앱·설치 파일에 키를 내장하지 않는다.
- 기존 tailnet 연결이 있으면 현재 연결을 표시하고 기존 계정 로그아웃 확인을 받는다. 동의 전에는 로그아웃하지 않는다. 동의하면 로그아웃 후 새 키로 진행한다.
- 확정 순서: 버전 확인 → 필요 시 업데이트(최신이면 다운로드·설치 생략) → 사용자가 승인한 기존 연결 로그아웃 → 새 키 등록. 온보딩 화면에서 로그아웃 동의를 받은 경우에만 전환한다.
- 설치·다운로드·업데이트 등 긴 대기 중 현재 단계와 진행 상황, 모션을 표시해 앱이 동작 중임을 알린다. 실제 측정되지 않은 진행률을 사실처럼 표시하지 않는다. 모션 축소와 가독성을 고려한다.

## 실패·재실행·지원

- 복구 가능한 실패는 한 번 자동 재시도한다. 소비된 일회용 키로 무조건 재등록하거나 사용자가 거부한 UAC·로그아웃을 자동 반복하지 않는다.
- 이미 해당 기기가 정상 연결되어 있으면 키 재사용 없이 남은 SSH 준비를 진행한다. 재등록이 꼭 필요하면 새 키를 요청한다.
- 복구되지 않는 실패는 마지막 리포트에서 실패 단계와 결과를 제공하고, 사용자가 복사해 인프라 관리자에게 전달할 수 있게 한다.
- 재실행 시 연결·SSH 상태를 확인하고 필요한 복구를 제공한다. 정상 기기에 키 재입력을 요구하지 않는다.
- 키는 영구 저장하지 않는다. 지원용 로그와 복사 리포트에 auth key·토큰·개인키를 포함하지 않는다.
- 실제 Tailscale 연결과 로컬 SSH 준비를 확인해 완료를 판정한다. 관리자 측 원격 접속까지 확인했는지 별도로 표시하고 접속 대상 계정과 로그 위치를 제공한다.
- 방화벽은 ADR 0006에 따라 모든 네트워크에서 SSH를 허용한다. 기존 Tailscale 전용 제한 결정은 대체됐다.

## 검증

- GHA windows-2022, windows-2025, windows-11-arm 세 러너를 유지한다.
- 실제 연결 자동 E2E는 GitHub OIDC와 Tailscale WIF로 tag:gha ephemeral 기기를 등록하고 작업 후 제거한다. 장기 Tailscale 자격 증명을 GHA에 저장하지 않는다.
- 첫 릴리스 전 Windows 10 x64와 Windows 11 x64의 VM/실기에서 수동 검증을 보완한다. 환경은 아직 확보하지 않았다.
- ARM64 native 빌드·패키징·실행을 검증하고 기본 보안키 두 개의 SSH 호환성도 확인한다. 표준 사용자 UAC 경로와 기존 설치 업데이트·tailnet 전환은 별도 시나리오에 포함한다.

# Linux 온보딩 앱 지원

상태: 백로그 — Windows 첫 배포 이후

## 목표

Rust GPUI 데스크톱 앱에서 전달받은 Tailscale 등록 키를 입력받고 Tailscale 연결 및 기본 관리자 공개키 두 개를 통한 SSH 원격 관리 준비를 완료한다.

## 작업

- 첫 지원 배포판·버전·CPU 아키텍처·그래픽 환경을 정하고 Rust GPUI 런타임 요구사항을 확인한다.
- Tailscale과 OpenSSH 설치, 권한 상승, 서비스 시작·자동 시작, 방화벽 설정을 지원 환경에 맞게 구현한다.
- SSH 대상 로컬 계정 정책을 정하고 기존 설정과 공개키를 보존하며 기본 공개키 두 개를 등록한다.
- 설치 패키지 형식·배포 파이프라인을 정한다.
- 실제 설치·재실행·보안키 SSH 접속과 비밀 비노출을 검증한다.

## 완료 기준

합의한 Linux 환경에서 첫 실행 키 입력 → 네트워크 연결 → SSH 원격 관리 준비를 실제 검증하고, 지원 배포판 및 시스템 의존성을 문서화한다. 모든 배포판 공통 지원을 가정하지 않는다.
